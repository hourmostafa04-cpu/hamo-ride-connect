# Remix of Hamoula Go

Create a clean mobile app for "HAMOULA" (Goods Transport Morocco) in Arabic RTL:

1. Onboarding: Role selection ("صاحب بضاعة" / "صاحب شاحنة").

2. Cargo Request Form: Pickup, Destination, Truck Type (صغيرة/متوسطة/كبيرة), Price (DH).

3. Driver Offers Screen (inDrive style list with Accept/Reject buttons).

4. Trip Tracking Screen with status bar and Chat preview.

Use green accents, clear large buttons, and include mock data.
